A cross-platform mobile application designed to make transportation more affordable by allowing passengers traveling in similar directions to **share rides and split the cost**.

**Highlights**

* 🚘 Ride booking and passenger/driver workflows
* 🤝 Shared rides between passengers traveling in similar directions
* 💰 Fare sharing to reduce individual travel costs
* 🔄 Real-time data synchronization
* 🔐 Firebase Authentication
* ☁️ Cloud Firestore

**Tech:** `Flutter` `Dart` `Firebase` `Cloud Firestore`
